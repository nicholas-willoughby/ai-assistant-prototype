# 🚀 Taipan - 혁신 팀 관리 시스템

**Innovation Team의 업무 생산성과 가시성을 높이는 통합 관리 시스템**

> 🎯 **8가지 우선순위 KPI** | 📊 **자동화된 분석** | 🤖 **AI 기반 조언** | 📋 **템플릿 기반 보고**

---

## 📦 시스템 구성

### 1️⃣ **KPI 대시보드** 
- `kpi-dashboard-template.md` - 📋 상세 마크다운 형식
- `kpi-dashboard.json` - 🤖 자동화/API용 JSON
- `kpi-dashboard.csv` - 📊 Excel/BI 도구용 CSV

### 2️⃣ **주간 보고서**
- `weekly-report-template.md` - 📋 완벽한 주간 보고서 템플릿
- `weekly-report.json` - 🤖 자동 수집/분석용
- `weekly-report.csv` - 📊 빠른 입력/분석용

### 3️⃣ **AI Assistant (Chat)**
- `taipan_ai_chat.py` - 🤖 AI 기반 텍스트 채팅
- `AI-CHAT-GUIDE.md` - 📖 사용 가이드

---

## 🎯 8가지 우선순위 KPI

1. 업무 생산성 향상 (85%)
2. 프로젝트 가시성 확보 (72%)
3. KPI 달성 지원 (68%)
4. 문서화 자동화 (90%)
5. 지식 축적 (75%)
6. 협업 품질 향상 (80%)
7. 반복업무 최소화 (70%)
8. 리스크 조기 발견 (45%) **🔴 긴급**

---

## 🚀 빠른 시작

```bash
# 1. 의존성 설치
pip install -r requirements.txt

# 2. API 키 설정
set COPILOT_API_KEY=your_api_key

# 3. AI Assistant 시작
python taipan_ai_chat.py
```

**자세한 가이드는 `AI-CHAT-GUIDE.md` 참고**
